HelloCoder 文档集中整理产品使用方式和服务条款。你可以从快速开始了解文档的阅读方式，并在注册、充值或调用服务前阅读用户协议与隐私政策。

## 快速开始

- [文档系统介绍](/docs/start/introduction)

## 服务条款

- [用户协议](/docs/legal/user-agreement)：账户使用、模型服务、计费及内容标准等约定。
- [隐私政策](/docs/legal/privacy-policy)：账户信息、调用日志、生成任务、上游处理和个人信息权利。

## 服务与支持

- [模型与定价](/pricing)：查看可用模型、分组及调用价格，按实际用量计费。
- [内容标准与举报](/docs/legal/user-agreement/#违规内容举报)：禁止内容、图片审查与处置、违规举报及申诉流程。
- [退款与计费规则](/docs/legal/user-agreement/#四-计费与不支持退款政策)：除适用法律强制要求外，不支持退款；账务纠错与失败请求的预扣额度退回另按协议处理。
- 客户支持、违规举报、申诉及隐私咨询邮箱：[report@hicoder.de](mailto:report@hicoder.de)。请提供必要的问题说明，不要发送密码、验证码或 API 密钥。

模型输出为 AI 生成内容，使用前应核验其准确性、适用性和权利情况。
